## 零、关键结论（人工撰写，非自动生成）

1. 优化分两类：**模型无关**（T1/T5/T1b/M2/F2/E1/I5，两模型同向受益）与**依赖容量**（I1/F1/FAQ 生成链路）。
2. **不要为省模型的力气改它的输入**：C1 首版把原文换成占位符，mask 精度从 0.83 崩到 0.54；改为「模型看原文 + 规则事后补漏」后达到 0.961。
3. **确定性短路（F2）性价比最高**：faq 4B 0.798→0.827、1.7B 0.577→0.663；且收益与模型容量负相关。
4. **上下文本来就短时，检索是负优化**：A1 只喂 top-3 信息点，两模型分别 -1.9/-5.7pt。
5. **指标会骗人**：F3 补全版 0.74→0.83 是把卡片原文机械补进答案；而判分器 v2 系统性偏严，faq 真实值比登记值高 4-8pt（v3 复核）。
6. **切题性判分（v4）无法鉴别补全型虚高**：补全版 0.817 仍高于诚实作答 0.798 → 该边界只能靠「不加补全」的对照配置来守。
7. **量化不是瓶颈**：Q4 vs Q8 差异全在 ±2pt 内，Q4 省 40% 内存 → 量产选 Q4_K_M。
8. **±3pt 是噪声**：同配置重跑 route 类指标漂 3 行样本≈3.3pt；intent 0.899 与阈值的 0.1pt 差距不构成结论。

## 八、读这份表要注意的三件事

1. **±3pt 是噪声**：同配置重跑（llama.cpp 非确定性）会让 route 类指标漂 3 行样本 ≈3.3pt。小于 3pt 的差异不要当结论。
2. **faq 有 v2/v3 两套口径**：v2 确定性、可复现，是本表登记值；v3 用 LLM 证据化复核，系统性上调 4-8pt（4B 0.788→0.827），对外汇报用 v3。
3. **delta 均相对各环境初始基线**，链条式采纳后单条实验的净变化请看记录备注里的「前值→后值」。
